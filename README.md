# LeadWalnut Backlink Performance Dashboard

Monthly backlink performance dashboard for leadwalnut.com (same layout as the Fortinet and Splashtop client dashboards, in LeadWalnut green).

- Each month's link: `https://leadwalnut-backlinking-dashboard-<month><year>.vercel.app`
- How the monthly update works, setup and troubleshooting: [SETUP_AND_TEST.md](SETUP_AND_TEST.md)
- Word doc layout, scripts and calculation rules: [MONTHLY_UPDATE.md](MONTHLY_UPDATE.md)

Local run: `npm ci && npm run dev`
